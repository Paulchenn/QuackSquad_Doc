\chapter{Challenge 2: Kreuzungsverhalten}
\label{ch:Challenge_2}
% Einleitung zur Challenge 2

Die zweite Herausforderung erweitert das Navigationsverhalten des Duckiebots um das sichere Verhalten an Kreuzungen. Aufbauend auf der Spurverfolgung muss das System erkennen, wann eine Kreuzung erreicht wird, an der roten Markierung anhalten und anschließend eine Richtungsentscheidung treffen – entweder links abbiegen, rechts abbiegen oder geradeaus weiterfahren. Dabei ist sicherzustellen, dass der Duckiebot nach dem Abbiegevorgang wieder korrekt auf die rechte Spur einbiegt, um möglichen Gegenverkehr zu vermeiden. Zur Signalisierung von Abbiegevorgängen kann optional ein Blinkersystem integriert werden. Diese Aufgabe diente der Implementierung einer elementaren Entscheidungslogik und stellt einen ersten Schritt in Richtung komplexerer, situationsabhängiger Navigation dar.
